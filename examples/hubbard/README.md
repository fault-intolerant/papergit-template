# 示范：Hubbard 模型的超交换

这个文件夹演示一个 issue 从打开到关闭的全过程。读完后删除整个 `examples/` 文件夹。

## issue

标题：[gap] Eq.(12) $J = 4t^2/U$

- 论文怎么说：由二阶微扰直接给出。第一次推导得到 $2t^2/U$。
- 出发点：Eq.(3)；半满， $U \gg t$
- 目标：Eq.(12)
- 验收标准：两格点精确对角化的能隙，在 $t/U \to 0$ 时趋于 $4t^2/U$
- 预计用时：2 小时

## 文件

- `test_eq12_superexchange.py`：检验。`test_eq12` 把推导结果与精确对角化比较；`test_mutations` 把结果故意改错五种方式，确认检验都会失败。
- `derivation.md`：推导，一句一行。推错的一步保留在"死路"一节。

## 提交历史

在真实的仓库中，这个 issue 留下的提交大致如下，新的在上。提交信息不渲染公式，直接写 LaTeX 源码。

```text
derive(eq12):  计入两个中间态，得到 4t^2/U

How:   两个双占据中间态各贡献 -2t^2/U；三重态的跳跃振幅相消
Check: test_eq12 通过，相对偏差按 (t/U)^2 减小
Refs:  #7

deadend(eq12): 只计一个中间态，得到 2t^2/U

How:   只考虑格点 2 -> 1 的跳跃
Check: test_eq12 失败，精确能隙与结果之比趋于 2
错因： 漏计格点 1 -> 2 的跳跃；当时以为两个方向是同一个过程
Refs:  #7

check(eq12):   两格点精确对角化，计算单态–三重态能隙

How:   Jordan–Wigner 构造 16 维 Fock 空间，取两电子子空间，按 S^2 区分单态和三重态
Check: test_mutations 通过，五种改错都被抓住
Refs:  #7
```

关闭 issue 时写的教训：二阶过程要把所有中间态列全，再看哪些矩阵元为零。
